01 — What I do

Fix the system, not the output.

/01

Build the harness

Agents need clear intent, good context, the right tools and fast feedback. You set the outcome. They do more of the work.

  • Repos built for people and agents
  • Shared specs, tools and evals
/02

Reshape the team

When code is cheap, attention is the constraint. Engineering moves upstream: framing problems, specifying intent, judging results.

  • Clear owners for every spec
  • Hire for judgment, not output
/03

Run agents in production

A demo is not production. Agents need boundaries, constant evaluation and a way back when they fail.

  • Permissions, evals and cost tracking
  • Rollback, audit and human sign-off
